# PixelCraft 像素工坊

面向手机/平板的像素画与逐帧动画编辑器。**TypeScript + React 18 + Canvas**，同一套源码同时产出：

- **Android APK**（自研无 Gradle 打包链，WebView + 原生桥接）
- **PWA / 网页版**（`app2/www`，可离线安装）

> 定位：把桌面像素画软件（Aseprite 风格）的算法搬到触屏，免费、无广告、可自用移植。
> 与 Aseprite / Resprite 的详细对比见 [`docs/COMPARISON.md`](docs/COMPARISON.md)。

## 1. 功能一览

| 模块 | 能力 |
|---|---|
| 绘制 | 铅笔 / 橡皮 / 油漆桶（连续·全局·**渐变**：按住拖动定方向与长度、松手落笔，RGB/2×2/4×4/8×8 颗粒；**相似色容差** 0–255 + **填充缝隙** 0–16px）/ **喷枪**（随机点大小区间 + 密度）/ 取色器；直线 / 矩形 / 椭圆 / 圆 / 多边形（可**从中心**绘制）/ **多点折线** / **曲线**（样条穿过所有点，点最后一个点结束）；**像素完美笔画**（去掉拐角多余像素）；笔刷 1–64、不透明度、**圆/方笔尖**、压感（`pointerType === "pen"`） |
| 选区 | 框选 / 魔棒（容差）/ 套索；全选、反选、清空、填充、复制、剪切、粘贴（含**粘为新图层 / 新画布**）、水平·垂直翻转、扩展、收缩、描边、裁切到选区、删除；移动 / 旋转 / 缩放（仿射）；**选区球手机端分三页**（常用 → 变形（斜切/透视、网格变形、完成、还原、裁切）→ 工具（翻转 / 扩展 / 收缩 / 描边 / 删除），每页 ≤7 项，触屏与电脑功能一致） |
| 图层 | 显示（**长按眼睛 = 只显示该图层**）、锁定、不透明度、12 种混合模式、重命名、新增 / 复制 / 上下移 / 向下合并 / 删除、长按拖拽重排 |
| 帧 | 新增 / 复制 / 删除 / 拖拽重排 / 单帧时长；**多选帧**批量复制、删除、统一时长 |
| 播放 | 单次 / 循环 / 乒乓 / 倒流（**按钮图标随模式变化**），逐帧时长驱动；**播放速度 0.25x / 0.5x / 1x / 1.5x / 2x**（时间轴控制条上的速度色片，改完立刻生效、重启后保持；**不改帧本身的时长**，导出的 GIF / `.aseprite` 仍是原时长）；**播放范围跟着动画标签走** |
| 动画标签 | **选中多帧一键加成标签**（Aseprite 风格的命名帧区间）：时间轴上方的彩色标签条 **点一下＝播放这一段**（点哪个就播哪个，标签重叠时也不会被别的标签顶掉）、**拖左右边缘＝直接改范围**、**右键 / 长按＝编辑器**（改名 / 换色 / 删除 / 选中这些帧）；**从标签内的任意一帧开始播放就只循环这一段**，播放起点不在任何标签里时播放整条时间轴；**播放中点别的标签的帧＝切换正在播的动画**；**多个标签重叠时自动分层显示**（各占一行，不会互相盖住）；标签随 `.pxc` 与 `.aseprite` 一起存取 |
| 洋葱皮 | 前后帧数（0–3）、不透明度、着色（前红后绿）、**循环环绕**（首末帧用蓝/琥珀色区分） |
| 对称 | 可旋转对称轴 0/45/90/135、四向对称、轴锁定；**开启后选区工具也会镜像** |
| 绘制 | 铅笔 / 橡皮 / 油漆桶（含渐变与缝隙填充）/ 取色器 / 喷枪 / 直线 / 矩形 / 椭圆 / 圆 / 多边形 / 折线 / 曲线 / 轮廓填充 / 矩形与套索选区 / 魔棒；**图案笔刷**（10 个内置图案 + 图案库面板，选区或整张画布都能存成图案；图案按画布坐标平铺，透明处不落笔（橡皮不受图案影响））|
| 调色板 | HSV 色轮 + HEX + 预设色板；色板 / 画布颜色 / 最近使用三种来源；长按色块全局换色；**去重 / 按色相·明度排序 / 合并预设色板**；`.gpl` 导入导出；**索引色模式**（画笔只落调色板颜色 + 把已有画面映射到调色板） 、**拖动颜色球到画布上直接油漆桶填充**（松手即填，原地松手仍是取色；底栏颜色块同样支持：未长按就拖动＝填充、长按＝快捷调色盘、点按＝调色板；落在非聚焦画布上会先聚焦再填，只记一条历史）；**色彩明暗**（移植 Aseprite 脚本 Color Shading v5.0）：给一个基色一次生成 **六条色阶**（明暗＝温度 + 饱和 + 明度、亮部、饱和、混色、微差、色相），另有**互补 / 三角 / 四角**三种和声配色；**暗部温度 / 亮部温度**（默认 215° 偏冷 / 50° 偏暖，各带色块）、**强度 / 亮度峰值 / 温度权重 / 槽位 3–25**（居中那格就是基色本身，填偶数自动 +1）可调；**基色块点一下打开调色板挑色**（选中的色就是新基色），生成色块**轻点＝前景色、长按＝把这格加进色卡、电脑右键＝背景色**，每条色阶行末尾的 **「+」把整行加进当前色卡、「保存」把整行存成一张新色卡**（不动眼下的色板），弹窗底部**「加入调色板」**一次把六条色阶去重后追加进当前色板（一条撤销）。入口：**颜色高级模式 → 明暗页**（见下一行） |
| 颜色分析 | **颜色高级模式**（调色板面板的「颜色高级模式」或主菜单进入；同一个面板分**分析 / 明暗**两页，明暗页即上一条的色阶生成器）：按范围（**画布**＝当前帧可见图层 / **当前图层** / **选区** / **所有帧**）统计每种颜色的**像素数与占比**、不透明 / 半透明 / 全透明分类、**用到的颜色数**；每个颜色标注「在调色板里 / 近似板色 / 板外」并给出**调色板里没用到的颜色**；**色相 / 饱和度 / 明度三条直方图**（主题令牌着色）；**近似色分组**列出"肉眼难分的重复色"（默认阈值 12，可调），一键**合并成代表色**（代表色＝组内像素最多的颜色，一条历史）；**颜色替换**：源色 / 目标色 / 容差（0–255）/ 范围 / 只替换不透明像素 / 保留半透明像素的 alpha / 目标色吸附到最近板色 —— 一条可撤销历史并提示改动了多少像素；每行还能「设为前景色」「选中这些像素」（按颜色建选区）；统计可**导出 CSV** |
| 缩放 | **高级缩放对话框**（画布球 →「高级缩放」，或从「修改尺寸」跳转）：六种重采样算法 —— **最近邻**（默认，保持硬边）/ **双线性** / **双三次**（Catmull-Rom）/ **区域平均**（缩小时最好）/ **Scale2x** / **Scale3x**（像素画专用整数倍放大，保硬边）；作用范围可选 **整个图像 / 当前图层 / 选区**，三者口径一致（把该范围的内容重采样成填写的宽高），但**只有「整个图像」会改画布尺寸**，图层 / 选区都按左上角贴回、画布不动（选区缩放后选区跟着变成新的大小）；**宽高 + 锁定比例 + 2× / 3× / 4× / ÷2 快捷倍率**（按当前范围的尺寸算）；**清理透明像素 RGB** 开关（防透明边缘发黑发彩）；**原图 / 缩放后并排预览**（按当前设置真的跑一遍算法；「对比预览」按钮开单独一屏，取的是**内容所在的那一块**、`整个图像`范围看的是**所有可见图层叠起来**的画面，取到透明处会显示棋盘格、整块为空时给一行提示）；算法在当前比例下不可用时会当场提示并说明降级到最近邻；一次操作只落一条撤销 |
| 等距图形 | **魔法球 →「等距图形」**：不用三视图，直接在画布上拖出一个 **2:1 等距体**（≈26.57°，像素画惯例）—— **立方体 / 楼梯 / 楔形 / 圆柱 / 金字塔 / 空心框** 六种形状，宽 / 深 / 高各 1–64 格，每格可选 **4px / 8px / 16px / 32px**（1×1×1 立方体正好是 4×4 / 8×8 / 16×16 / 32×32 px）；**拖四个菱形角抓手改宽深、拖黄色方块上下调高度、拖整块移动**全部吸附 2:1 栅格，拖动时只画半透明预览、松手才落笔，栅格与足迹框都跟图形严丝合缝对得上；外观可选 **单色三档 / 当前前景色三档 / 三面自定**（顶面亮、右面中、左面暗，强度 / 亮度峰值 / 温度权重可调）+ **接触阴影** + **1px 描边**；形状专属参数（楼梯级数与方向、楔形坡向、圆柱半径与空心、金字塔平顶、空心框壁厚）都在「外观」里；**生成**写进当前图层、「生成到新图层」一条撤销连图层一起回退；参数条实时显示 `宽×深×高 · 像素尺寸 · 体素数` 并提示是否超出画布 |
| 特效 | **描边（宽度/内·外·居中/颜色）**、**投影（偏移 x/y、颜色、不透明度）**、**模糊（半径）**、外发光、反色、灰度、居中、智能裁剪 —— 需要参数的特效会弹出窗口并**实时预览**，颜色参数点色块即可打开调色板面板 |
| 导出 | PNG（整帧 / 图层 / 选区 + 倍率 + 背景）、GIF（**帧范围**、逐帧时长、透明）、精灵表 + JSON、**Aseprite `.aseprite` 工程**（图层 / 帧 / 帧时长 / 混合模式 / 调色板原样保留，可直接在 Aseprite 里继续编辑）、调色板 `.gpl`、分图层批量导出 |
| 导入 | **Aseprite `.ase` / `.aseprite`**（RGBA / 灰度 / 索引色，含多图层、多帧、链接帧、调色板；1024×1024 上限内按原样还原，可新建或作为图层）、图片（新建 / 作为图层）、精灵表按单元格切帧、参考图浮窗、色板 |
| 多画布 | **同一无限空间内打开多张画布**：画布上方游戏风格标题栏（点按聚焦 / **双击平滑适配** / 拖动移动画布）、每张画布独立记住图层与帧、**整个工程共用一条撤销栈**（可全局撤销与回放）、**画布球两页**（常用：新建 / 重命名 / 改尺寸 / **锁定位置** / 关闭画布（**可撤销找回**）；更多：色相调整 / 导出 / 平铺 / 引用画布 / 提取图层）、**画布吸附成组**（拖近自动吸附、留白高亮、整组移动、标题栏右侧可解除；范围/留白/进出颜色都在设置里调）、标题栏左侧预览按钮、**引用画布**（按图层或整张引用另一张画布，实时联动、双向同步：默认按图层引用，源画布每个图层各一条引用层，画哪条就改哪条）、**提取图层为画布**、**多预览框**（按需出现、绑定各自画布、可拖动与捏合缩放）、**选区跨画布移动**（把浮动选区直接拖到另一张画布上松手即搬过去，PC 与触屏一致；目标图层锁定时整个移动作废并提示）、**选区自由变换（对齐 Aseprite，选区球 →「变形」页）**：**十六个固定图标抓手**＝四个角 + 四条边中点各带缩放（8），角外侧 30px 各带旋转（4）、边中点外侧 30px 各带斜切（4），**贴着选区框**、一眼可辨（方块 / 扁矩形＝缩放、圆形箭头＝旋转、双向斜线＝斜切；触屏与电脑同一套；小选区把旋转 / 斜切收窄到 20px，**不隐藏**）；**枢轴可拖**并有 9 档预设（中 / 四角 / 四边中点），**双击枢轴＝复位到内容正中**（画面一格不动，只改绕哪里转），**枢轴是内容上的一个点**：拖动内容 / 缩放 / 旋转时标记跟着内容走、拖它时 1:1 跟手，且挪枢轴时画面逐像素不动；**框与抓手同源**（恒等变换下变换框与选中框逐像素重合、按下的瞬间十六个抓手都不跳位），**缩放的不动点＝对角那个锚点**（拖右下角时左上角钉住、被拖的边跟手），**斜切的基准线＝对面那条边**（拖哪条边哪条边跟手、对面一动不动），旋转中心＝画出来的那个枢轴（选区不在画布原点也照样转 90° 就是 90°）；旋转吸附到**干净角**（0 / 26.565 / 45 / 63.435 / 90…，像素不被转糊），斜切钳在 ±85°；四个开关 chip＝等比 / 角度吸附 / 网格吸附 / 复制（PC 上分别等价 Shift / — / Alt / Ctrl）；**一次会话一条 undo**（换抓手、连着拖都算同一次，第二次拖在上一次的结果上继续累加；点「完成」才落历史，切工具 / 切帧 / 「还原」也会收尾）；整数平移走**像素精确通道**（逐像素搬运、不重采样），其余一律最近邻（90° 倍数旋转在格点上同样无损）；**自由变形**（同一颗球的「自由变形」页：「斜切 / 透视」拖四角、「网格变形」拖 3×3 网格点，拖动实时预览、**松手不落笔**、点「完成」落下一条历史、可随时「还原」；进入变形本身不动图层，宽或高只有 1 像素的选区会被拒绝；采样最近邻、拉伸不留洞；**控制点＝像素下标**（画在**像素中心**上而不是像素边界上；**支撑半像素吸附**：可落在两格之间的边界线上（`x.5`），拖动时显示一位小数坐标，选区球「变形」页里可随时切成整像素）；**抓取不跳位**（控制点直接落在指针上，拖到哪就是哪；按在内容上拖动＝整块内容连同控制点一起走）、**变换中途切过来会先把当前结果烘焙成浮动内容**（控制点落在眼前这块内容上，不会跳回原位）、**控制点与网格线画在图像之上**（不会被自己变出来的像素盖住）、变形期间**不自动平移**视口，恒等变换逐字节无损、选区里每个像素都被覆盖、**默认空白工程**（无画布时显示引导卡片，工程自动保存） |
| 工程 | `.pxc` 工程文件（**唯一文件单位**：内含全部画布、每张画布的位置/帧/图层选择，以及**一条工程级操作记录**，可全局撤销与回放）、**按间隔自动保存**（默认 5 分钟，可调 1–60 分钟；存纯 JSON + 像素 RLE，不存图片）、**自动保存多版本**（默认保留最近 5 版，可调 1–12；内容没变不占新版本）、**自动保存历史面板**（主菜单 →「自动保存历史」或设置 → 数据：逐版恢复 / 导出成 `.pxc` / 删除）、**崩溃恢复提示**（上次没正常退出时启动后说明并列出可回退的版本）、设置文件导入导出；**工具/颜色/对称/参考图/文档默认值全部跨启动保持** |
| 交互 | 双指缩放/平移、像素放大镜、边缘自动平移、**旋转画布内容 90°**（画布球 → 更多，宽高互换、选区跟随、可撤销）、返回手势逐层关闭 + 二次确认退出；**每个手势的功能都可重映射**（画布内外双击、双指双击、三连击、四指滑动、长按）；抽屉面板（调色板、时间线等）在**手机竖屏铺满全屏**，横屏与电脑模式仍是右侧抽屉 |
| 体验 | 声明式设置（搜索 / 单项恢复默认 / 分组折叠，含**手势与触控**组）、46 步模块化新手引导（真操作演示）、更新日志（版本选项卡 + 分类折叠）、操作记录与回放、帧预览、中英双语 |
| AI 工具服务 | **本地 AI 工具服务（默认关闭，要在设置里手动打开）**：在 `127.0.0.1` 上开一个本地端口，外部 AI 助手 / 命令行凭 token（每次启动随机生成）调用 **61 个工具**读写这块画布 —— 读文档摘要与像素区域、画任意折线与形状、油漆桶填充（含容差 / 封口 / 渐变）、擦除一块区域、平移 / 缩放 / 旋转、8 种特效（描边 / 内描边 / 投影 / 外发光 / 反色 / 灰度 / 圆角 / 模糊）、生成等距体、图层 / 帧 / 调色板 / 标签操作；放行范围分三档（**只读**（默认）/ **允许绘制** / **全部**），档位只决定要不要确认与默认列出哪些工具，**不决定工具能不能调**；删图层、清空画布、缩放画布、擦除、变换这类破坏性操作**每一项都要确认**，没确认时文档一个字节不动；**一轮 AI 的几十次调用合成一条撤销**（历史标签固定带 `ai: ` 前缀，外部助手断线或超时会自动放弃这一轮并把历史还给你）；**只绑本机、不对局域网开放、服务默认关闭**，APK 为此新增了 `INTERNET` 权限（Android 上监听本地端口也要它），但应用不发起任何出站请求、也没有内置任何 key；电脑上可以用 `node toolchain/ai-server.mjs` 起同一份协议做调试（接口见 [`docs/API.md`](docs/API.md) §24） |

| 应用内助手 | **在应用里说一句话 → AI 调工具 → 预览后应用（APK / 电脑壳里才有）**：设置 → AI 助手填端点 / 模型 / key（OpenAI 兼容的基地址，**第一次打开就已经指向 DeepSeek**），主菜单 →「AI 助手」打开**浮动小窗**；模型用 function calling 调用 61 条工具里的任意一条，一轮结束先给出「这一轮改了哪块」的预览，点「应用」才写进历史（**一轮只占一条撤销**，标签带 `ai: ` 前缀；历史面板里一眼认出）、点「放弃」逐字节回到这一轮开始（中途报错、关掉面板也自动放弃）；删图层、清空画布这类破坏性操作**每次都弹确认框**，拒绝就一个字节都不动；**API key 只存在本机**（不进设置导出 / 工程文件 / 诊断文本，设置页可一键清除），**线上 PWA 不内置任何 key、也不显示这个面板**（只有 APK 与电脑壳里有桥接），浏览器里连输入框都不挂、不发任何请求 |

## 3. 目录结构

```
src/
├─ engine/      纯像素引擎（无 DOM）：doc / cel / paint / shape / effects / ops / history / color / adjust
├─ tools/       工具层：registry（工具表与笔刷状态）、stroke（笔迹引擎）、select（选区与变换）、xform（自由变换的纯几何：锚点 / 命中圈 / 枢轴 / 干净角 / 解算）
├─ app/         应用层：session（状态中枢）、settings（设置注册表）、guide（引导注册表）、playback（循环模式）、gestures（手势映射）、history-io（标量历史载荷）、
│               ai-doc（文档文本化）、ai-tools（AI 工具表）、ai-draw（AI 落笔适配层：笔迹 / 形状 / 填充 / 擦除 / 特效 / 变换）、
│               ai-turn（回合事务）、ai-rpc（AI 协议路由）、ai-serve（本地服务生命周期）、ai-presets（厂商预设：DeepSeek 默认）、ai-chat（应用内助手的整轮循环 + function calling）
├─ render/      view（视口 / 手势 / 渲染）、compositor（合成）、rect（脏矩形工具）、onion（洋葱皮布局）
├─ servers/     服务层：render（RenderServer：合成缓冲 / 合成键 / 失效区域 / 多画布缓存）、viewport（缩放平移与坐标数学，纯函数）、
│               input（手势策略与算术）、gesture（TapMachine 轻点序列 + GestureController 指针事件入口）
├─ io/          bridge（原生桥接）、exporters、gifread、project（.pxc）、aseread/asewrite（Aseprite .ase/.aseprite）、zlib（自写 inflate + CompressionStream 压缩）、autosave、clipboard
└─ ui/          React 界面：App、timeline、modals、changelog、guide(+demo/layout)、hold、preview、i18n、style.css、AiPanel（应用内助手面板 + 助手浮动球 ChatBall）、AiWindow（助手浮窗，portal 到 body）
   └─ ui/kit/    UI 控件库：Dialog、Form（Row/ChipGroup/Segmented/Switch/NumberField/ColorField）、primitives、scrub、令牌与演示页
tests/          引擎与逻辑测试（无 DOM 依赖，node 直接跑）
android/        自研 APK 工程（AndroidManifest + MainActivity + 图标）
app2/www/       PWA 产物（index.html + 构建后的 app.js/style.css）
toolchain/       开发辅助脚本（devserver 静态服务、make-icon 图标生成、ai-server 本地 AI 工具服务宿主、pc-mcp 电脑侧 MCP 入口、pc-shell 电脑桌面壳 + 模型请求同源代理）
```

### 架构要点

- **引擎层零 DOM**：`engine/`、`app/`、`tools/`、`servers/` 全部可在 Node 下测试（7655 条断言跑在纯数据上，含 UI 控件与令牌契约；`npm test` 末尾会打印条数）。
- **服务层**：合成与缓存归 `RenderServer`、视图数学归 `ViewportServer`（`docs/API.md` §15b），手势策略归 `input.ts`、轻点序列 + 四个指针入口 + 触点会话状态归 `gesture.ts`（§15c / §15c2 / §15c3），`render/view.ts` 只做 blit、覆盖层与各工具的动作体 —— 这是 `docs/ARCHITECTURE.md` 里 Server 化的落地进度。
- **声明式注册表**：设置项写在 `src/app/settings.ts`，引导步骤写在 `src/app/guide.ts`；新增功能 = 一条声明 + i18n 文案，界面自动生成。
- **增量渲染**：笔迹只重合成/重绘改动区域（`Rect` + `composeRectInto` + `celToCanvasRect`），一帧一次绘制（rAF 合并）。
- **撤销栈**：`history.pushPixels`（像素）/ `pushStruct`（结构快照）/ `record`（标量前后值）三类，所有破坏性操作都可单步撤销。
- **原生桥接**：`window.PixelBridge`（保存 / 打开 / 震动 / Toast / 常亮），网页端自动降级为 `<a download>` 与 `<input file>`。

## 5. Web 版部署（GitHub Pages）

仓库用双分支模型：**`master` = 全部源码**（APK 与 Web 共用同一套），**`main` = 只放部署用的静态站点**。

- 在线地址：<https://deerluuu.github.io/PixelCreate/>
- `main` 的内容是构建产物，**不要手工编辑**；改完源码后在 `master` 执行：

  ```sh
  sh scripts/publish-web.sh --push     # 重新构建 app2/www → 生成 main 的新提交 → 推送
  ```

- `main` 上的 `.github/workflows/pages.yml`（源文件在 `master` 的 `web/pages.yml`）会在推送后
  自动发布到 Pages；仓库 Settings → Pages → Source 需选 **GitHub Actions**。
- 构建命令与本地一致（`scripts/build-web.sh`，默认 `--minify`：1.2MB → 约 730KB，Pages 上 gzip 后约 180KB）；
  仓库、APK、Pages 三处用的是**同一份产物**，改完源码三处一起更新。
- `app2/www/js/telemetry.js` 只在本地 devserver 上报（localhost / 127.0.0.1 / 局域网 IP / `*.local`），
  在 Pages 与 APK（`file://`）里完全静默。
